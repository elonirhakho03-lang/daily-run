# Daily Run — Routine Tracker

A personal Progressive Web App (PWA) designed to help manage daily routines, habits, study activities, mood, schedules, and personal progress in one place.

## Features

- **Daily Habit Tracking** — Add and complete routines across morning, afternoon, and evening.
- **Monthly Habit Grid** — View habit completion history and track streaks across the month.
- **Journal** — Record daily reflections and personal entries.
- **Schedule** — Organize weekly activities and reminders.
- **Mood & Wellness** — Track mood, symptoms, and general wellness.
- **Study Tools** — Manage study-related activities, notes, and reading lists.
- **Custom Themes** — Choose from multiple visual themes and customize the app's appearance.
- **Notifications** — Supports browser notifications and scheduled reminders while the application is running.
- **Progress Tracking** — Keep track of daily completion and personal progress.
- **Progressive Web App** — Designed to work as a web application with PWA capabilities.

## Technologies

## Project Structure

```text
daily-run/
├── index.html
├── manifest.json
├── sw.js
└── README.md
```

### `index.html`
Contains the main application interface, styling, and JavaScript functionality.

### `manifest.json`
Defines the Progressive Web App configuration, including the application name, display mode, theme, and start URL.

### `sw.js`
Implements the service worker used for caching and PWA functionality.

## Purpose

Daily Run was developed as a personal productivity and routine-management application, combining habit tracking, study organization, journaling, scheduling, mood tracking, and progress monitoring in a single interface.
